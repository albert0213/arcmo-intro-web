# 유입·도입 신청 기록 (구글 시트)

arcmo.xyz 의 커뮤니티 랜딩(`/lesson/`), 신청 폼(`/apply/`), 본 페이지가 보내는 기록을
구글 스프레드시트 하나에 모읍니다. 서버도 비용도 없고, 새 신청이 오면 메일로 알려 줍니다.

| 시트 | 내용 |
|---|---|
| `events` | 방문·버튼 클릭. 브라우저마다 만든 무작위 id 와 유입 경로만 (개인정보 없음) |
| `leads` | 도입 신청. `처리 상태`·`메모` 칸은 직접 고쳐 쓰면 됩니다 |
| `통계` | 유입 경로별 방문자 → 자세히 보기 → 신청 버튼 → 신청 완료. 매시간 + 신청 올 때 다시 계산 |

## 처음 한 번 (5분)

1. 구글 드라이브에서 새 스프레드시트를 만듭니다 (이름 예: `Arcmo 유입 기록`).
2. 메뉴 **확장 프로그램 → Apps Script** 를 열고, 기본 `Code.gs` 내용을 지운 뒤
   이 폴더의 [`Code.gs`](Code.gs) 를 통째로 붙여 넣고 저장합니다.
3. 위쪽 함수 목록에서 **`setup`** 을 고르고 **실행** → 권한 허용
   (시트 읽기·쓰기, 메일 보내기, 트리거). 실행 로그에 **통계 열쇠(STATS_KEY)** 가 찍힙니다.
4. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   → 배포 → 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사합니다.
5. 그 URL 을 [`assets/track.js`](../../assets/track.js) 맨 위 `ENDPOINT` 에 넣고 커밋합니다.
6. 통계는 `https://arcmo.xyz/stats/#key=<STATS_KEY>` 로 한 번 열면 그 브라우저에 열쇠가 저장됩니다.

알림 메일은 스크립트를 만든 구글 계정으로 갑니다. 다른 주소로 받으려면
Apps Script **프로젝트 설정 → 스크립트 속성** 에 `NOTIFY_EMAIL` 을 추가하세요.

## 코드를 고친 뒤

**배포 → 배포 관리 → (연필) → 버전: 새 버전 → 배포**. 이렇게 하면 웹 앱 URL 이 그대로라
`track.js` 를 다시 고칠 필요가 없습니다. (새 배포를 만들면 URL 이 바뀝니다.)

## 링크 만들기

커뮤니티마다 `from=` 값만 바꿔서 씁니다. 영문 소문자·숫자·`-`·`_`, 32자까지.

| 어디에 | 링크 |
|---|---|
| 게임원 | `https://arcmo.xyz/lesson/?from=gameone` |
| 네이버 카페 (예) | `https://arcmo.xyz/lesson/?from=navercafe` |
| 바로 신청 폼 | `https://arcmo.xyz/apply/?from=gameone` |

통계 화면에 한글 이름으로 보이게 하려면 `Code.gs` 의 `SOURCE_NAMES` 에 한 줄 추가하세요.
`from` 이 없어도 이전 사이트가 게임원·네이버·다음 등이면 자동으로 알아봅니다.

## 무엇을 세나

| 이벤트 | 언제 |
|---|---|
| `landing_view` | `/lesson/` 열림 |
| `click_more` / `click_apply` | 랜딩의 *Arcmo 자세히 보기* / *도입 신청하기* |
| `main_view` / `main_click_apply` | 본 페이지 열림 / 본 페이지의 신청 버튼 |
| `apply_view` / `form_start` | 신청 화면 열림 / 첫 입력 |
| `lead_submit` | 신청 완료 (`leads` 시트에도 한 줄) |
| `lead_fallback` | 온라인 접수가 안 돼 메일 보내기로 넘어감 |

방문자 수는 `*_view` 이벤트를 보낸 서로 다른 브라우저 수입니다. 같은 사람이 폰과 PC 로 들어오면 두 명으로 셉니다.
