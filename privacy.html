개인정보 처리방침

Arcmo 스윙 분석 앱 · 시행일 2026년 11월 3일

Arcmo(이하 “회사”)는 스윙 분석 앱 “Arcmo”(이하 “앱”)를 이용하는 분의 개인정보를 「개인정보 보호법」에 따라 처리합니다. 앱은 회원가입 없이 기기에서 만든 익명 키로 기록을 구분하며, 영상과 분석 결과를 모델 학습에 사용하지 않습니다.

1. 처리 목적

  • 스윙 영상 분석과 등급·코멘트·기록 제공
  • 하루 무료 분석 횟수 관리와 서비스 오류 확인
  • 이용자가 요청한 레슨 문의의 전달과 연락
  • 이용자가 동의한 경우에 한한 새 서비스 소식 안내와 이용 통계 분석

2. 처리하는 항목

구분항목수집 시점
필수앱이 생성한 익명 기기 키, 타석(좌·우), 야구 경력, 활동 지역(시·구), 만 19세 이상 확인 여부, 동의 기록첫 분석 전 정보 입력
필수이용자가 선택하거나 촬영한 스윙 영상(영상에 담긴 소리 포함), 분석 구간·임팩트 시점, 분석 결과(관절 좌표·지표·등급)분석 요청
선택이름, 연락처, 희망 시간, 메모레슨 문의
선택앱 이용 이벤트(익명화한 식별자 포함)이용 통계 동의 시
자동오류 발생 시 오류 종류와 앱 내 위치, 요청 시각앱 사용 중

앱은 위치(GPS)와 연락처를 수집하지 않습니다. 앱에서 촬영할 때 마이크 권한을 허용하면 영상과 함께 소리를 녹음합니다. 영상의 소리는 배트에 공이 맞는 순간(임팩트 시점)을 찾는 데만 쓰고, 회사 서버에서 그 시점을 계산한 뒤 분석 서버(RunPod)에는 소리를 뺀 영상만 보냅니다. 마이크 권한을 거부해도 촬영과 분석을 이용할 수 있고, 이때는 임팩트 시점을 직접 표시할 수 있습니다.

3. 보유 및 이용 기간

  • 원본·분석용 영상: 분석 완료 후 최대 90일이 지나면 자동 삭제합니다.
  • 분석 결과와 프로필: 이용자가 앱에서 전체 삭제를 요청할 때까지 보관합니다.
  • 레슨 문의: 처리 완료 후 1년간 보관 후 파기합니다. 문의에 첨부한 리포트 링크는 7일 후 열람할 수 없습니다.
  • 법령에 따라 보존이 필요한 경우 해당 기간 동안 보관합니다.

4. 제3자 제공

회사는 이용자의 동의 없이 개인정보를 제3자에게 제공하지 않습니다. 레슨 문의 시 이용자가 별도로 동의한 경우에만 선택한 레슨 업체에 이름·연락처·희망 시간·메모와 분석 리포트를 제공하며, 업체는 문의 응대 목적으로만 이용하고 응대 완료 후 파기합니다.

6. 파기 절차와 방법

보유 기간이 끝나거나 삭제 요청을 받으면 지체 없이 파기합니다. 전자 파일은 복구할 수 없는 방법으로 삭제합니다. 클라우드에 보관된 사본은 회사가 확인 후 삭제하며, 이미 다른 사람이 저장한 사본은 회수할 수 없습니다.

7. 이용자의 권리와 행사 방법

  • 앱 설정 → 내 데이터에서 내 데이터를 파일로 내려받을 수 있습니다.
  • 앱 설정 → 분석 동의를 철회하고 모두 삭제로 영상·분석·프로필·문의·공유 링크 삭제를 요청할 수 있습니다.
  • 공유한 리포트 링크는 설정에서 언제든 중단할 수 있습니다.
  • 앱을 삭제한 뒤에는 기기 키를 확인할 수 없으므로 baseball@arcmo.xyz로 분석 날짜를 알려 주시면 확인 후 처리합니다.

8. 안전성 확보 조치

전송 구간 암호화(HTTPS), 기기 키의 암호화 저장(Android 암호화 저장소·iOS 키체인), 서버 접근 권한 최소화와 운영자 인증, 레슨 업체별 열람 권한 분리를 적용합니다.

9. 만 19세 미만 이용 제한

앱은 만 19세 이상을 대상으로 하며, 첫 분석 전에 이를 확인합니다. 만 19세 미만의 정보가 수집된 사실을 알게 되면 즉시 삭제합니다.
